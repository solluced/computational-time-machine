# Computational Time Machine (CTM) v2.0

## A Measurement and Experimental Framework for Generational AI R&D Systems

**Author:** Nickolay Gorlanov (Nick G.)  
**Version:** 2.0  
**Date:** September 10, 2026  
**DOI:** https://doi.org/10.5281/zenodo.22689836  
**Zenodo:** https://zenodo.org/records/22689836  
**Status:** Technical preprint; research proposal and falsifiable systems hypothesis; not peer reviewed.  
**License:** CC BY-ND 4.0

Version 2.0 expands the original CTM concept into a measurement and experimental framework for testing whether verified generational inheritance can produce cumulative AI R&D acceleration beyond matched flat-agent baselines.

The technical preprint formalizes the Technological Time Compression Ratio (TTCR), introduces Causal Inheritance Depth (CID), defines matched experimental arms and ablations, and adds explicit compute, energy, physical-latency, provenance, verification, safety, and falsification requirements.
