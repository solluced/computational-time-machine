## Summary

The **Computational Time Machine (CTM)** is a proposed research architecture for testing whether technological R&D time can be compressed by a persistent, generational AI research ecosystem. Rather than scaling only the number of parallel agents working on fixed tasks, CTM introduces **Civilization-in-the-Loop (CitL)**: successive AI research generations inherit only independently validated discoveries, tools, models, simulators, experimental capabilities, and engineering improvements from predecessor generations.

The proposal introduces the **Technological Time Compression Ratio (TTCR)** as an evaluation target and emphasizes closed-loop physical validation through robotic laboratories and automated experimentation.

## Core thesis

> The meaningful “time machine” is not transport into the future; it is the ability to compute and validate technological futures faster than chronological civilization can reach them.
